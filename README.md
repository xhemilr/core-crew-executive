# Core Crew Solutions — website (Concept B · Executive)

Dark navy and gold design: a quick-start request bar, one table showing every trade at every level, a process timeline up to the work permit, crew sizes, pricing approach and a quote form.

Static site, no build step — `index.html` is the whole site. Served with GitHub Pages from the `main` branch root.

**Draft status:** the page carries a `noindex` robots tag so search engines skip it. Remove it when this concept goes live.
Photos are hotlinked from Unsplash (free licence) and should be downloaded and self-hosted before launch.
